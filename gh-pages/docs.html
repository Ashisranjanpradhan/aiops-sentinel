Developer Guide

Platform Documentation & Deployment

Everything required to deploy AIOps Sentinel locally, configure OpenTelemetry pipelines, and enforce readiness in CI/CD.

1. Quick Start: Local Staging Boot

Clone the repository and spin up the complete local observability stack using Docker Compose: 

# 1. Clone repository
git clone https://github.com/Ashisranjanpradhan/aiops-sentinel.git
cd aiops-sentinel

# 2. Configure environment template
cp .env.example .env

# 3. Boot staging containers
docker compose -f docker-compose.staging.yml up -d

# 4. Open Gateway
open http://localhost:8088

Configure your first administrator account in .env using INITIAL_ADMIN_EMAIL and a strong INITIAL_ADMIN_PASSWORD. Hardcoded or default credentials are prohibited in staging and production.

2. CLI Codebase Assessment

Run a static production-readiness assessment directly against a local repository or ZIP package: 

# Run assessment against a local folder
python -m app.cli.assess --path ./my-service --format sarif --output report.sarif

# Upload a ZIP codebase to the running Sentinel API
curl -X POST http://localhost:8088/api/v1/assessments/upload \
  -H "Authorization: Bearer $SENTINEL_TOKEN" \
  -F "file=@service.zip"

3. OpenTelemetry Collector Configuration

Configure microservices to export OTLP traces and metrics to the Sentinel collector endpoint: 

export OTEL_EXPORTER_OTLP_ENDPOINT="http://sentinel-gateway:4318"
export OTEL_EXPORTER_OTLP_PROTOCOL="http/protobuf"
export OTEL_SERVICE_NAME="payment-service"

4. GitHub Actions CI/CD Policy Quality Gate

Enforce production-readiness in pull requests before code merges into main: 

name: Production Readiness Gate
on: [pull_request]

jobs:
  readiness-check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Run AIOps Sentinel Assessment
        run: |
          docker run --rm -v ${{ github.workspace }}:/code \
            ghcr.io/ashisranjanpradhan/aiops-sentinel-backend:latest \
            python -m app.cli.assess --path /code --min-score 80 --sarif results.sarif
      - name: Upload SARIF to GitHub Security Tab
        uses: github/codeql-action/upload-sarif@v3
        with:
          sarif_file: results.sarif
