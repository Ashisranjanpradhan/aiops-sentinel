Architectural Boundary & Isolation Model

Network Segregation

Only the NGINX Reverse Proxy exposes ports to the public network. PostgreSQL, Redis, Prometheus, Loki, and Tempo remain strictly internal on dedicated Docker bridge networks.

Transactional Concurrency

Database mutations and automated remediations use PostgreSQL Advisory Locks (pg_try_advisory_xact_lock) to eliminate race conditions between concurrent SRE actions.

Telemetry Buffering

The OpenTelemetry Collector decouples high-volume microservice metric streams from persistent storage, buffering events during network latency spikes.
