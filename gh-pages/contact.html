Static Documentation Notice

This GitHub Pages deployment serves static public project documentation and research metrics:

  • No Backend Ingestion: Static Pages hosting does not process form submissions or collect personal data.
  • Direct Feedback: Maintainers review inquiries submitted through GitHub Issues and Discussions.
  • Vulnerability Reports: Security researchers should consult SECURITY.md for responsible reporting.
  • Open Source: Licensed under Apache 2.0 for community audit and collaboration.

Dynamic Application Deployment

GitHub Pages hosts only the static project website and documentation. The dynamic AIOps Sentinel software platform (Next.js web console, FastAPI backend, PostgreSQL database, Redis queues, and OpenTelemetry pipelines) runs on separate containerized cloud hosting. To deploy the runtime application, follow the local Docker deployment guide in Documentation.
